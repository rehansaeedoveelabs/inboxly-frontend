# Inboxly Frontend

Standalone React marketing application UI for Inboxly.

## Stack

- Vite
- React (JavaScript)
- React Router
- Tailwind CSS
- Recharts
- lucide-react

## Notes

- Frontend-only prototype with mock data
- No Laravel code in this repository
- No real Shopify, email, or SMS integrations

## Scripts

```bash
npm install
npm run dev
npm run build
```
